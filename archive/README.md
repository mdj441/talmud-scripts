# ארכיון: הסקריפטים הישנים

ארבעת הסקריפטים כאן הוחלפו בסקריפט המאוחד **"תלמוד - כלי אוטומציה"** (גרסה 4), שמותקן מהקישור ב-[README הראשי](../README.md).
הם נשמרים לתקופת מעבר בלבד, **ללא תחזוקה**, למי שעדיין צריך את ההתנהגות הישנה:

| כלי | גרסה אחרונה | קובץ |
|---|---|---|
| קליטת תלמידים | 3.2 | `תלמוד - קליטת תלמידים.user.js` |
| עזיבת תלמידים | 5.0 | `תלמוד - עזיבת תלמידים.user.js` |
| טיפול בהודעות | 5.0 | `תלמוד - טיפול בהודעות.user.js` |
| דיווח חודשי | 4.0 | `תלמוד - דיווח חודשי אוטומטי.user.js` |

אין להתקין סקריפט ישן יחד עם הסקריפט המאוחד: שניהם רצים על אותם דפים, ואצווה עלולה לרוץ פעמיים.
הקבצים יוסרו בגרסה עתידית.
