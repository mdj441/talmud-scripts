# כלי אוטומציה למערכת תלמוד

סקריפט Tampermonkey אחד לעבודה שוטפת במערכת תלמו"ד (talmud.edu.gov.il): קליטת תלמידים, עזיבת תלמידים,
טיפול בהודעות ודיווח חודשי. חינמי, לשימוש אישי. מרדכי יאקאב.

## הסקריפט המאוחד (גרסה 4)

**[⬇️ התקנת "תלמוד - כלי אוטומציה"](https://github.com/mdj441/talmud-scripts/raw/refs/heads/main/dist/talmud-tools.user.js)**

אחרי ההתקנה מופיע בכל דף של תלמו"ד כפתור צף קטן בפינה. לחיצה עליו פותחת מגירה אחת (צמודה לקצה המסך) עם לשוניות,
לפי הדף שאתה נמצא בו:

| דף באתר | לשוניות |
|---|---|
| פרטי מוסד (סניף) | קליטת תלמידים · עזיבת תלמידים · דיווח חודשי |
| פרטי סוג לימוד | קליטת תלמידים |
| הודעות (Association) | הודעות |

מה משותף לכל הלשוניות:
- **קלט כמו באקסל**: מדביקים טורים (טאבים או פסיקים), עם שורת כותרת או בלי, או טוענים קובץ אקסל.
- **אצווה שלא נתקעת**: שורה בעייתית מקבלת סטטוס ברור וממשיכים לשורה הבאה. בסוף: דוח "מה נשאר" עם הוראה לכל שורה.
- **עצור** בכל רגע (כפתור או מקש Escape). ריצה שעברה טעינת-דף ממשיכה מעצמה.
- **תוצאות לאקסל**: "העתק לאקסל" (הדבקה ישירה) או ייצוא CSV.
- **יומן פעילות** עם מזהים ממוסכים, בטוח לשליחה כשמדווחים על בעיה.
- הסקריפט מתעדכן אוטומטית דרך Tampermonkey.

> **לא להתקין יחד עם הסקריפטים הישנים** של אותם כלים. שני סקריפטים על אותו דף עלולים להריץ אצווה כפולה.
> כבו (או הסירו) את הישנים לפני שמתקינים את המאוחד.

## התקנה

### שלב 1: התקנת Tampermonkey

Tampermonkey הוא תוסף חינמי להרצת סקריפטים בדפדפן:

| דפדפן | קישור |
|-------|-------|
| Chrome | [Chrome Web Store](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) |
| Firefox | [Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/tampermonkey/) |
| Edge | [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) |

### שלב 2: מצב מפתח + אישור סקריפטים (Chrome / Edge)

> **חובה לבצע את שני החלקים, אחרת הסקריפט לא יפעל כלל.** ב-Firefox אין צורך בשלב זה.

**חלק א: מצב מפתח.** פתחו את עמוד התוספים (`chrome://extensions/` או `edge://extensions/`) והפעילו את **"מצב מפתח"**
(ב-Chrome: המתג בפינה הימנית העליונה; ב-Edge: בתפריט הצד).

**חלק ב: אישור לסקריפטים של משתמשים.** באותו עמוד לחצו על **"פרטים"** של Tampermonkey
(או ישירות: `chrome://extensions/?id=dhdgffkkebhmkfjojejmpbldmpobfkfo`), גללו לתחתית והפעילו את
**"אישור לסקריפטים של משתמשים"** (Allow user scripts).

### שלב 3: התקנת הסקריפט

לחצו על קישור ההתקנה למעלה. Tampermonkey יציג מסך התקנה: לחצו **Install**.
אם הקישור לא עובד: אייקון Tampermonkey → "Create a new script" → `Ctrl+A`, `Delete`, הדבקת קוד הסקריפט, `Ctrl+S`.

## שימוש

### קליטת תלמידים

1. היכנסו לדף המוסד של סניף כלשהו (או ישירות לדף סוג-לימוד). פתחו את החלונית ואת הלשונית "קליטת תלמידים".
2. הזינו את התלמידים באחת משלוש דרכים, כולן מגיעות לאותה טבלה:
   - **הדבקה מאקסל**: העתיקו את הטורים (עם או בלי שורת כותרת) והדביקו בתיבה. הטבלה מתמלאת.
   - **קובץ אקסל**: "טען קובץ אקסל". יש גם "הורד תבנית לאקסל" עם הכותרות הנכונות.
   - **ישירות בטבלה**: שורה לתלמיד. סניף, סוג לימוד וארץ נבחרים מרשימה (אפשר גם להקליד).
3. הטורים: `סניף | סוג לימוד | ת.ז./דרכון | שם פרטי | שם משפחה | תאריך לידה | ארץ | מגדר | מצב משפחתי`.
   חובה: שלושת הראשונים. **דרכון**: גם תאריך לידה (DD/MM/YYYY) וארץ (שם בעברית כפי שהוא באתר, או קוד מספרי).
   **תלמיד שאינו מוכר למערכת**: גם שם פרטי, שם משפחה ותאריך לידה (מגדר ומצב משפחתי אופציונליים; ברירת המחדל: זכר, נשוי).
   שורה עם בעיה מסומנת באדום, והסבר מופיע כשמעמידים עליה את העכבר.
4. אפשר לקבוע תאריך תחילת לימודים (ריק = ברירת המחדל של האתר), ואז **"התחל קליטה"**.
5. הסקריפט עובר סניף וסוג-לימוד לפי הצורך (טעינות-דף הן חלק מהתהליך; אין לסגור את הלשונית).
6. בסיום: טבלת סטטוסים (נקלט / כבר קיים / נקלט (תלמיד חדש) / שגיאה / ...), "העתק תוצאות לאקסל", ודוח "מה נשאר לעשות".

דוגמת הדבקה:
```
סניף	סוג לימוד	ת.ז./דרכון	שם פרטי	שם משפחה	תאריך לידה	ארץ
01	300	123456789
12	600	AB1234567			15/03/1995	צרפת
03	600	123456780	משה	כהן	10/10/1990
```

### עזיבת תלמידים

בדף המוסד, לשונית "עזיבת תלמידים": מדביקים טורים `סניף | ת.ז.`, קובעים תאריך עזיבה (ריק = היום) וסיבה,
ולוחצים "התחל עזיבה". הסקריפט מחפש כל תלמיד, מבצע עזיבה ומאמת בגריד. תלמיד שלא נמצא או שכבר עזב מקבל סטטוס והריצה ממשיכה.

### דיווח חודשי

בדף המוסד, לשונית "דיווח חודשי": "התחל" עובר סניף אחר סניף, שולח את הדיווח בכל סניף שהכפתור פעיל בו,
ומדלג על סניפים שכבר דווחו. אפשר לעצור בכל רגע; בסיום מוצג סיכום: נשלחו, דולגו, שגיאות.

### הודעות

בדף ההודעות (`Association/Default.aspx`), לשונית "הודעות":

1. **סקירה** (ברירת המחדל): "סרוק" אוסף את כל ההודעות במצב "נשלחה" לטבלה אחת בתוך החלונית.
   הודעות כפולות (אותו נושא ואותו תלמיד) ממוזגות לשורה אחת עם כמות.
2. לכל שורה בוחרים **החלטה**: אישור מעבר / דחיית מעבר / סמן כטופל / דלג. ברירת המחדל: בקשת מעבר → אישור,
   כל השאר → טופל. כפתורי-צובר ("כל בקשות המעבר: אישור", "כל השאר: טופל", "הכל: דלג") וסינון מהיר לפי ת.ז. או נושא.
3. **הצלבה מול המצבת** (רשות): מדביקים מאקסל שתי עמודות, סניף ות.ז., והטבלה מראה לכל הודעה אם התלמיד
   במצבת ובאיזה סניף. בקשת מעבר היא בקשה של מוסד אחר להעביר אליו תלמיד שלנו: אם התלמיד עדיין במצבת
   (בכל סניף) השורה מסומנת "ממתין" (יש לאשר או לדחות); אם אינו במצבת היא מסומנת "כנראה בוצע". שני התגים
   הם רמז לבדיקה, ההחלטה לא משתנה מעצמה; הכפתור "כל 'כנראה בוצע': סמן כטופל" מחיל אותה על השורות המסומנות.
   הודעת "מעבר תלמיד" (מעבר ממוסדך או אל מוסדך אושר) היא אינפורמטיבית וברירת המחדל שלה "סמן כטופל".
4. **"בצע לפי הטבלה"**: הסקריפט מבצע את ההחלטות, מאמת מול הגריד אחרי כל פעולה, ומציג דוח "מה נשאר".
   "דלג" לא נוגע בהודעה.

**מצב גורף**: מטפל בכל ההודעות בלחיצה אחת לפי ברירות המחדל (בלי סקירה).
**דרך אקסל** (אופציה מתקפלת): "העתק לאקסל" או "הורד אקסל", עריכת עמודת "פעולה" באקסל, הדבקה חזרה, "טען" ו"בצע".

## למפתחים

- הקוד ב-`src/` (מודולים: `core/` תשתית משותפת, `tools/` הכלים, `ui/` החלונית). `npm run build` בונה קובץ
  userscript יחיד ל-`dist/talmud-tools.user.js` (בנייה דטרמיניסטית; הבדיקות משוות את הקובץ לבנייה טרייה).
- `npm test`: בדיקות יחידה (`node:test`) על הלוגיקה הטהורה.
- `npm run test:e2e`: הסקריפט האמיתי רץ בכרום אמיתי (Playwright, הכרום המותקן במחשב) מול **סביבת-דמה** של דפי
  האתר ב-`mock/`. אין התחברות ואין נתונים אמיתיים. `HEADED=1` מציג את הדפדפן.
- `npm run mock`: שרת מקומי של סביבת-הדמה עם הסקריפט מוזרק, לצפייה ידנית: <http://localhost:8787/>.
- יומן השינויים: [CHANGELOG.md](CHANGELOG.md).
